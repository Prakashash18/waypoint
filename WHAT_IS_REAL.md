## What IS Real: Atlas CLI Data

The flight search results come directly from the Atlas CLI and are **real bookable flights**.

### Real Atlas CLI Commands You Can Run

```bash
export PATH="$HOME/.local/bin:$PATH"

# 1. Check CLI health
atlas-flight doctor --json

# 2. Switch to sandbox
atlas-flight environment use sandbox --json

# 3. Check auth status
atlas-flight auth status --json

# 4. Search KUL → SIN (REAL FLIGHTS)
atlas-flight search --origin KUL --destination SIN --depart 2026-09-15 --adults 1 --json

# 5. Search with airline filter
atlas-flight search --origin KUL --destination SIN --depart 2026-09-15 --adults 1 --airline AK --json

# 6. Search BKK → SIN
atlas-flight search --origin BKK --destination SIN --depart 2026-09-15 --adults 1 --json

# 7. Search with multiple fare families
atlas-flight search --origin KUL --destination SIN --depart 2026-09-15 --adults 1 --multiple-fare-families --json

# 8. Verify a specific offer (use offer_id from search results)
atlas-flight offer verify --offer-id off_4d63b38e53331b26c5da6ebf --json

# 9. Confirm price
atlas-flight booking confirm-price --offer-id off_4d63b38e53331b26c5da6ebf --json

# 10. Seat selection
atlas-flight booking seat --booking-id <booking_id> --preference auto --json

# 11. Create order
atlas-flight order create --booking-id <booking_id> --passengers '{"passengers":[{"title":"Mr","first_name":"John","last_name":"Doe","date_of_birth":"1990-01-01","email":"john@example.com","phone":"+60123456789"}]}' --json

# 12. Check order status
atlas-flight order status --order-id <order_id> --json

# 13. Pay for order
atlas-flight order pay --order-id <order_id> --payment-confirmation-id <payment_id> --json
```

## What is NOT Real: Flight Delays

The **delays panel** shows **simulated/fake data**. It is randomly generated for demo purposes.

### Why?

The Atlas CLI is a **booking** tool. It does not have:
- ❌ Flight status tracking
- ❌ Real-time delay information
- ❌ Departure board data
- ❌ Historical delay patterns

### How to Tell

In the code, the delay data is generated by `_get_simulated_delays()` in `flight_status.py`:

```python
# This is FAKE data
delay_minutes = random.choice([15, 30, 45, 60, 90, 120, 180])
flight_num = f"AK{random.randint(100, 999)}"
```

### How to Get Real Delay Data

Add a flight status API:

**Option 1: AviationStack (Free tier — 100 requests/month)**
```bash
# .env
AVIATIONSTACK_API_KEY=your-key-here
```
Sign up: https://aviationstack.com

**Option 2: FlightAware AeroAPI ($0.01/request)**
Sign up: https://flightaware.com/aeroapi

**Option 3: OpenSky Network (Free, no key needed)**
https://opensky-network.org

## The Honest Answer

**Real from Atlas CLI:**
- Flight search → real flights, real prices, real availability
- Booking flow → real booking, real payment, real ticket issuance
- All four checkpoints → enforced by the Atlas Skill

**Not real:**
- Flight delays → randomly generated for demo

**To make delays real**, you need a separate flight status API (AviationStack, FlightAware, or OpenSky).
